## Differentiation thesis (PROPOSED)

Helix is the **personal operating system** that:

1. Picks today’s action from real context
2. Explains the pick
3. Lets the user complete it in the real world
4. Validates the completion on the server
5. Writes a durable identity (character, not a selfie streak)
6. Recovers with the user instead of punishing them
7. Grows from fitness into a full development lattice without rewriting the engine

If Arise is “anime gym with a daily quest,” Helix is “the System that already knows what matters today.”
